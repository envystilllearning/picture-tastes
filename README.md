# picture-tastes

The entry image is a molten chocolate lava cake, the winner of a six-call vision panel that tied it 0.60 against ramen before the cake took the tie-break as the verified pick.
It ships as an 800x800 PNG of 872,742 bytes, comfortably inside the 1 MiB and 1024x1024 limits, and the included program copies entry.png into the output directory on every run.
